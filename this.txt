👉 When a function is stored as an object’s property, we call it a method

That’s it. No extra magic.

Compare with a normal function
Normal function
function getUserDetails() {
    console.log("Hello");
}
This function:

Exists on its own

Does not belong to any object
→ ❌ Not a method

Function inside an object (method)
const user = {
  getUserDetails: function () {
    console.log("Hello");
  }
};
This function:

Belongs to user

Is called using user.getUserDetails()
→ ✅ Method

Why JavaScript calls it a method (conceptually)
Because it:

Operates on the object’s data

Uses this to access object properties

this.username
This makes it behavior related to the object, not just a random function.

Good question — this is where this becomes very clear 👍
Let’s go step by step and clear the confusion.

Case 1: Multiple users as separate objects (BEST & COMMON WAY)
const user1 = {
  username: "Prathamesh",
  loginCount: 8,
  getUserDetails() {
    console.log(`Username: ${this.username}`);
  }
};

const user2 = {
  username: "Amit",
  loginCount: 3,
  getUserDetails() {
    console.log(`Username: ${this.username}`);
  }
};

user1.getUserDetails(); // Username: Prathamesh
user2.getUserDetails(); // Username: Amit
Why this works here
user1.getUserDetails() → this === user1

user2.getUserDetails() → this === user2

✅ Same method logic, different object context

Case 2: Multiple users inside one object
const users = {
  user1: {
    username: "Prathamesh",
    loginCount: 8
  },
  user2: {
    username: "Amit",
    loginCount: 3
  },

  getUserDetails(userKey) {
    console.log(`Username: ${this[userKey].username}`);
  }
};

users.getUserDetails("user1"); // Prathamesh
users.getUserDetails("user2"); // Amit
What this means here
this === users

this[userKey] dynamically selects which user

Case 3: Best scalable approach (Constructor / Class) ⭐
If you’ll have many users, this is the real-world solution.

Using constructor function
function User(username, loginCount) {
  this.username = username;
  this.loginCount = loginCount;
}

User.prototype.getUserDetails = function () {
  console.log(`Username: ${this.username}`);
};

const user1 = new User("Prathamesh", 8);
const user2 = new User("Amit", 3);

user1.getUserDetails(); // Prathamesh
user2.getUserDetails(); // Amit
Why this is powerful
One method definition

Many objects

this automatically refers to the instance

Key rule to remember 🔑
this always refers to the object that calls the function, not where the function is written.

Scenario	What this refers to
user1.method()	user1
user2.method()	user2
users.method()	users
Constructor/class method	The instance
